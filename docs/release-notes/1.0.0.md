First release of realsf2, a MIDI, SoundFont 2 and SFZ converter for Nintendo 64 games. It runs each sequence through a performer that follows the game's sound engine. It records the resulting notes and controllers. Each sequence gets a MIDI file and a SoundFont containing its instruments. SFZ files are written beside them.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more images onto `realsf2.exe`. You can also use a terminal. `realsf2 --help` lists the options. Output goes in a folder beside each image.

For macOS, follow the build instructions in the README. macOS builds include `Realsf2.app`. Drop images onto the app in Finder to convert them.

## What it does

- **Input.** Reads Nintendo 64 images in any of the usual byte orders (`.z64`, `.n64` and `.v64`). realsf2 recognises a game by the SHA-1 of its image.
- **Sound engines.** Follows the SDK sequence players, the N64 Music Tools in their early and later forms, the three forms of the EAD engine, the Intelligent Systems engine and the standard MIDI file player of Hey You, Pikachu!. Each performer follows the clock, voice rules and volume arithmetic of its engine.
- **Game profiles.** Each supported game has a profile of what the game code does to its songs: levels, tempos, channel masks and choices between arrangements. A song that the game plays in more than one way gets a track for each way.
- **MIDI.** The engine channels become MIDI tracks. Volume, pan, pitch bend and the reverb send become controllers. The main loop is marked for players that support loop markers.
- **SoundFont.** The samples, tuning, loops and envelopes of each instrument, at the levels of the engine. Output targets FluidSynth.
- **SFZ.** One file per MIDI track, with WAV samples that all songs of an image share. Output targets sfizz 1.2.
- **Reports.** Lists the approximations that MIDI, SoundFont or SFZ require for each sequence.

## Supported games

Chameleon Twist, Chameleon Twist 2, Cruis'n World, GoldenEye 007, Hey You, Pikachu!, Mario Kart 64, Mario Tennis, Paper Mario, Pokémon Puzzle League, Pokémon Snap, Pokémon Stadium, Pokémon Stadium 2, Super Mario 64, The Legend of Zelda: Majora's Mask, The Legend of Zelda: Ocarina of Time and Wave Race 64. The table in the README gives the version of each.

## Known limitations

- SoundFont and SFZ envelopes decay in straight lines of decibels. The engine envelopes decay in straight lines of amplitude. realsf2 fits each envelope to the one in the game.
- The game reverb is left to the player. CC91 sets the send.
- Sound effects that a song starts stay out. So do fades that the game code starts during play.
- An image without a profile converts from the SDK sequence files and the largest bank, at an assumed output rate of 22050 Hz.
- See "Differences from the game" in the README for the full list.
