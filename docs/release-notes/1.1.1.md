A maintenance release. realsf2 converts every game to the same files as 1.1.0.

## Downloads

| File | Contents |
|---|---|
| `realsf2-1.1.1-win-x64.zip` | Windows x64 executable, `README.md`, `LICENSE` and `THIRD-PARTY-NOTICES.md` |

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more images or ROM sets onto `realsf2.exe`. You can also use a terminal. `realsf2 --help` lists the options. Output goes in a folder beside each image or set.

For macOS, follow the build instructions in the README. macOS builds include `Realsf2.app`. Drop images or ROM sets onto the app in Finder to convert them.

## Changes

- **Paths outside the code page on Windows.** realsf2 now runs with UTF-8 as its code page. An image or a folder whose name the system's code page can't hold, such as a Japanese name on an English system, now opens.
- **The libraries.** realsf2 now builds on seqlib 1.4.0, xsflib 1.10.0 and ntdlib 3.6.0.

As in 1.1.0. See "Differences from the game" in the README for the full list.
