A release with a fix to the samples. realsf2 now writes each wave through a filter that follows the console's resampler. Bright waves used to play louder than in the game. realsf2 converts the music of Nintendo 64 games to MIDI, SoundFont 2 and SFZ files. The MIDI files stay the same as in 1.0.0. Convert an image again to get the new SoundFonts and SFZ samples.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more images onto `realsf2.exe`. You can also use a terminal. `realsf2 --help` lists the options. Output goes in a folder beside each image.

For macOS, follow the build instructions in the README. macOS builds include `Realsf2.app`. Drop images onto the app in Finder to convert them.

## Changes

- **The resampler's filter.** The game plays every wave through the console's resampler. The resampler has 64 filters. Each of them cuts the highest frequencies. On average over the filters, a wave loses about 2.3 dB at a quarter of its sample rate and 7.4 dB at half of it. realsf2 now writes each wave through a filter with that average response. The SoundFonts and SFZ samples used to hold the waves unfiltered.
- **The README on interpolation.** A player's interpolation cuts the highest frequencies again. The README now says how FluidSynth's settings compare. With its default 4-point interpolation, FluidSynth plays the brightest waves quieter than the game does. With 7th-order interpolation, which the shell command `interp 7` sets, it comes closer.
- **The libraries.** realsf2 now builds on seqlib 1.3.0, xsflib 1.8.0 and ntdlib 3.2.0.

## Known limitations

As in 1.0.0. The game's resampler picks one of its 64 filters for each output sample. realsf2 writes the average of their responses. In the game, a note at a wave's recorded pitch stays on one filter. The brightest waves then play up to 2.3 dB louder. See "Differences from the game" in the README for the full list.
